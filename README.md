# Rocky Kumar Portfolio Website

A responsive personal portfolio built with plain HTML, CSS, and JavaScript.

## Run locally
1. Extract the ZIP file.
2. Open `index.html` in a browser.

For local development, you can also use the VS Code Live Server extension.

## Personalize before publishing
- In `index.html`, replace `your.email@example.com` with your professional email address.
- Add your profile photograph by replacing the initials avatar (`RK`) with an image.
- Add verified DOI, Google Scholar, ORCID, GitHub, and publication links where appropriate.
- Review the academic timeline and publication descriptions for accuracy.

No framework or build step is required.
